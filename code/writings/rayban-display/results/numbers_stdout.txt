3. Snell's law: air to glass (n = 1.5) at 30 degrees
==============================================================================
sin(30) = 0.500; sin(theta2) = 0.5 / 1.5 = 0.333; theta2 = 19.5 deg
glass to air at 30 deg: sin(theta2) = 1.5 x 0.5 = 0.75, theta2 = 48.6 deg (bends away from the normal)
glass to air at 45 deg: 1.5 x sin(45) = 1.061 > 1, so no ray can leave: total internal reflection

4. Critical angle for total internal reflection, against air
==============================================================================
water                          n = 1.333  critical angle = 48.6 deg   TIR window = 41.4 deg
common glass / acrylic         n = 1.5    critical angle = 41.8 deg   TIR window = 48.2 deg
best glass Meta had in 2016    n = 1.8    critical angle = 33.7 deg   TIR window = 56.3 deg
lithium niobate                n = 2.3    critical angle = 25.8 deg   TIR window = 64.2 deg
silicon carbide (Orion)        n = 2.7    critical angle = 21.7 deg   TIR window = 68.3 deg

5. Fresnel reflection at normal incidence (why bare glass reflects about 4%)
==============================================================================
R = ((1.5 - 1)/(1.5 + 1))^2 = 0.040 = 4%

9. Pixels per degree
==============================================================================
diagonal pixels = 600 x sqrt(2) = 848.5
side angle (small-angle) = 20 / sqrt(2) = 14.14 deg
pixels per degree = 848.5 / 20 = 42.4  (Meta says 42)
one pixel spans 60 / 42.4 = 1.41 arcminutes; 20/20 vision resolves about 1 arcminute = 60 ppd
to reach 60 ppd over the same 14.14 deg square you would need 849 x 849 pixels
with Guttag's estimate of about 400 x 400 effective pixels: 28.3 effective pixels per degree
a square 30 deg diagonal field at 42 ppd needs about 891 x 891 pixels
  that is 2.2 times the 600 x 600 = 360,000 pixels of the Ray-Ban Display
a square 70 deg diagonal field at 42 ppd needs about 2079 x 2079 pixels
  that is 12.0 times the 600 x 600 = 360,000 pixels of the Ray-Ban Display

14. Where the projector light goes: how much enters the pupil
==============================================================================
solid angle of a 14.14 x 14.14 deg square = 0.0606 sr
pupil 1.5 mm: area 1.77 mm^2, flux into the eye = L x A x Omega = 0.54 mlm = 0.05% of the 1 lm from the projector
pupil 3.0 mm: area 7.07 mm^2, flux into the eye = L x A x Omega = 2.14 mlm = 0.21% of the 1 lm from the projector
pupil 4.0 mm: area 12.57 mm^2, flux into the eye = L x A x Omega = 3.81 mlm = 0.38% of the 1 lm from the projector
if no light were lost, 1 lm at 5,000 nits over that cone would fill 3299 mm^2 (a 57 x 57 mm square)

==============================================================================
