== one Elo update, by hand ==
A has 1200, B has 1100.  expected score of A: 1 / (1 + 10^((1100 - 1200)/400)) = 0.6401
A wins (score 1), K = 32:  A -> 1200 + 32 x (1 - 0.6401) = 1211.5   B -> 1100 - 32 x (1 - 0.6401) = 1088.5
B wins instead (an upset):  A -> 1200 - 32 x 0.6401 = 1179.5   B -> 1100 + 32 x 0.6401 = 1120.5
