== 2. How long does that take? ==
tiny GPT on the laptop: 37,367 tokens/s x 6 x 12,318,720 params = 2.76 TFLOP/s achieved
   C = 9.08e+14 FLOPs / 2.76e+12 FLOP/s = 5.5 minutes (pure training steps)
Llama 3 405B: 3.79e+25 / (16,384 H100 x 989 TFLOP/s x 40% MFU) = 67.7 days
GPT-3 175B: 3.15e+23 / (16,384 H100 x 989 TFLOP/s x 40% MFU) = 0.6 days
Llama 3 405B at the laptop speed: 4.35e+05 years

== 3. Kaplan et al. (2020) power laws ==
  N =   1e+06:  L(N) = (8.8e13 / N)^0.076 = 4.016 nats/token
  N =   1e+07:  L(N) = (8.8e13 / N)^0.076 = 3.371 nats/token
  N =   1e+08:  L(N) = (8.8e13 / N)^0.076 = 2.830 nats/token
  N =   1e+09:  L(N) = (8.8e13 / N)^0.076 = 2.376 nats/token
  N =   1e+10:  L(N) = (8.8e13 / N)^0.076 = 1.994 nats/token
  N =   1e+11:  L(N) = (8.8e13 / N)^0.076 = 1.674 nats/token
  every 10x more parameters multiplies the loss by 10^-0.076 = 0.839 (a 16.1% drop)

== 4. Chinchilla parametric fit (Approach 3): L(N, D) = E + A / N^alpha + B / D^beta ==
  Gopher 280B, 300B tokens: 6ND = 5.04e+23;  L = 1.69 + 0.052 + 0.251 = 1.993
  Chinchilla 70B, 1.4T tokens: 6ND = 5.88e+23;  L = 1.69 + 0.083 + 0.163 = 1.937

== 5. Compute-optimal N and D for a budget C (minimise L subject to C = 6ND) ==

== 7. Memory for mixed-precision training with Adam (bytes per parameter) ==
  bf16 weights 2 + bf16 gradients 2 + fp32 master weights 4 + Adam m (fp32) 4 + Adam v (fp32) 4 = 16 bytes/parameter
  our tiny GPT  :  1.23e+07 x 16 B =       0.18 GiB  (before activations)
  Qwen2.5-0.5B  :  4.94e+08 x 16 B =       7.36 GiB  (before activations)
  Llama 3 8B    :     8e+09 x 16 B =     119.21 GiB  (before activations)
  Llama 3 405B  :  4.05e+11 x 16 B =   6,034.97 GiB  (before activations)
